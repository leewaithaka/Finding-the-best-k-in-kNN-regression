# Finding the Best k in kNN Regression

## Project Overview
A Python machine learning project that identifies the optimal number of neighbors (**k**) in a k-Nearest Neighbors (kNN) regression model.  
The project demonstrates practical application of kNN regression, model evaluation, and hyperparameter tuning to improve predictive accuracy.

## Tools & Libraries
- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib / Seaborn (for visualizations)

## Dataset
The project uses datasets with numeric features and a continuous target variable, suitable for regression tasks. Datasets can be CSV files containing the necessary input features.

## Key Features
- Data cleaning and preprocessing
- Splitting dataset into training and testing sets
- Implementing kNN regression for different k values
- Evaluating model performance using Mean Squared Error (MSE)
- Plotting MSE vs k to select the optimal number of neighbors
- Optional visualization of predicted vs actual values

## Results & Insights
- Optimal k value identified for the dataset
- Understanding how k affects model accuracy
- Demonstrates practical implementation of machine learning regression techniques
- Can be adapted to other regression problems with kNN
